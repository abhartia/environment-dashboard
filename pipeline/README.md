# envdash: the data pipeline

Every published number comes through here: fetch the raw file, snapshot its bytes (sha256), transform, validate,
cross-check against the producer's own statements, and export to `data/` (and `data-private/` for values we may show
but not redistribute). See `../AGENTS.md` for the rules and `../docs/runbook.md` for operations.

Run everything from `pipeline/` with uv: `uv run envdash --help`, `uv run envdash <command> --help`.

## Commands

| Command | What it is for |
|---|---|
| `envdash refresh [-s <source>…] [--force]` | The weekly run in one step: fetch, then build, then validate, then write `data/v1/status.json`. Exits non-zero if any source failed, after writing what succeeded. |
| `envdash fetch [-s <source>…]` | Re-check each source's licence quote against its terms page, download every automatic artifact (resolving `discover` listings, sending API keys from the environment), and record new bytes as snapshots. A source's pointers in `manifests/current.json` move only when all its artifacts fetched cleanly. |
| `envdash build [--force]` | Run every transform whose build key changed (inputs, transform code, `uv.lock`, the data contract, registry and literature files), validate it, run the publisher cross-checks and export to `data/` or `data-private/` by licence class. A failed transform keeps its previous export. |
| `envdash validate [--registry-only]` | Check the registry, every snapshot manifest, the current pointers and every published file (canonical form, licence side, catalogue hashes, datapackage, SHA256SUMS, time order of paleo series). `--registry-only` checks just that every source and literature YAML loads. |
| `envdash snapshot add --source <id> --artifact <id> --file <path> --note "<who, from where>" [--url …] [--accessed YYYY-MM-DD]` | Record a file a person downloaded (manual sources, or hosts that block scripts) and make it the artifact's current snapshot. |
| `envdash snapshots pull` | Fill the local cache `pipeline/.snapshots` from R2 on a fresh machine or runner: every snapshot `current.json` points at and every input of every published indicator, each checked against its sha256. Needs the R2 environment variables only when something must be downloaded, and fails naming any snapshot that was never archived. |
| `envdash archive [-s <source>…] [--no-r2] [--no-wayback]` | Upload raw snapshots to R2 (public bucket only when the terms allow re-hosting, private otherwise) and request Wayback Machine captures of landing, terms and open data pages. |
| `envdash resolve [-s <source>…]` | Show the URL each `discover` artifact resolves to today, reading only the listings (downloads nothing). Use it when adding or debugging a `discover` rule. |
| `envdash status` | Print `data/v1/status.json`: each source's state, vintage, terms check and last success. |
| `envdash openapi [--stdout]` | Write `schema/openapi.json` from the models (the web generates its client from it with `npm run gen:api`); `--stdout` prints it for drift checks. |
| `envdash private push` | After a build, upload every no-derivatives and display-only export the catalogue lists to the private R2 bucket. |
| `envdash private pull` | Before a web build elsewhere, download those private exports, each checked against the catalogue's `export_sha256`. |
| `envdash geo build` | Rebuild `geo/entities.csv` (the entity crosswalk) from the current Natural Earth snapshots and the stations, aggregates and territories declared in `envdash/geo.py`. |
| `envdash docs licensing` | Regenerate `../docs/licensing.md` (every registered source, its licence, class, mirror rule and terms check) from `sources/*.yaml`. Run it after any registry change; a test fails if it is stale. |
| `envdash report-issues` | In CI: open, update or close one GitHub issue per failed source, and file an issue when a source's next release is due. |

## Layout

| Path | |
|---|---|
| `sources/<id>.yaml` | The source registry: terms quoted verbatim, licence class, obligations, artifacts. |
| `literature/<id>.yaml` | Values quoted from papers and reports, each checked against the snapshot's text before publishing. |
| `src/envdash/models.py` | The data contract (pydantic). A change here is a change to the published files and the web types. |
| `src/envdash/transforms/<domain>/<name>.py` | One module per source family; each exposes `transforms(paths)`. |
| `manifests/` | `current.json` (which snapshot each artifact builds from), `snapshots/<sha256>.json` (one per raw file), `builds/<id>.json` (build keys and publisher checks). |
| `geo/entities.csv` | The entity crosswalk (`envdash geo build`). |
| `schema/openapi.json` | Generated by `envdash openapi`. |
| `tests/fixtures/` | Byte-exact slices of real open-licence snapshots, each with a `.provenance.json` sidecar. |

## Tests

`uv run pytest -q` runs on fixtures only. `uv run pytest -q -m snapshot` needs the full raw snapshots in
`.snapshots/` (`envdash fetch`, or `envdash snapshots pull` from R2). `uv run ruff check` and `uv run ruff format`
keep the style.
